# 📊 Vendor Performance Analysis

## 🚀 Overview

Analyzed vendor-level business performance by integrating sales, purchases, inventory, and freight datasets. The goal was to uncover contribution patterns, cost inefficiencies, and key drivers of vendor performance.

---

## 🧠 What This Project Does

* Aggregates multi-source data into vendor-level insights
* Calculates contribution and profitability metrics
* Identifies top-performing vendors
* Analyzes cost components (freight, inventory) impacting margins

---

## ⚙️ Key Steps

* Data cleaning and preprocessing
* Dataset merging (vendor, brand-level joins)
* Vendor-level aggregation (sales, purchases, inventory, freight)
* Feature engineering (contribution %, margins)
* Exploratory analysis with visualizations

---

## 📊 Core Outputs

* **Vendor Performance Table** → consolidated KPIs
* **Top Vendors Analysis** → ranking by contribution
* **Contribution Metrics** → % share of sales/purchases
* **Cost Insights** → freight and inventory distribution

---

## 🔍 Key Insights

* Revenue and purchases are concentrated among a few vendors
* Freight costs significantly vary and impact profitability
* High-revenue vendors are not always high-margin
* Inventory allocation shows imbalance across vendors

---
